# Surya Hema Tejaswani Sura — Portfolio

A modern, responsive personal portfolio for a Full Stack Java Developer (Fresher).

## Files
- `index.html` — main portfolio page
- `style.css` — responsive design, animations and components
- `script.js` — mobile menu, reveal animations, active navigation and dynamic year
- `assets/Surya_Hema_Tejaswani_Sura_Resume.pdf` — resume used by the Download Resume button
- `assets/favicon.svg` — favicon
- `assets/og-image.svg` — Open Graph/social preview image

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
1. Create a GitHub repository named `portfolio`.
2. Upload all files and the `assets` folder.
3. Go to Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.
